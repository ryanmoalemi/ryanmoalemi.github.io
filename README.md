# Ryan Moalemi’s blog

This is the GitHub Pages blog for [ryanmoalemi.blog](https://ryanmoalemi.blog).

## Adding a new post

1. Copy the structure of [`blog/hello.html`](blog/hello.html) into a new HTML file in `blog/`.
2. Update the title, date, and post content.
3. Link the new post from [`blog/index.html`](blog/index.html).

The site is a small, hand-written collection of notes and ideas.
